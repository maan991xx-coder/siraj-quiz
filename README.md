# مسابقة سراج الثقافية

موقع مسابقة ثقافية يومية من **مجموعة سراج** في جامعة السلطان قابوس: سؤال كل يوم من الأحد إلى الأربعاء الساعة 7:00 مساءً (15 نوفمبر – 9 ديسمبر 2026)، وأسرع إجابة صحيحة بوقت الخادم تفوز.

- الواجهة: `index.html` (HTML + CSS + JavaScript بدون مكتبات) + `manifest.json` + `sw.js`
- الخادم: `Code.gs` على Google Apps Script مع Google Sheets كقاعدة بيانات
- الخط: ثمانية (Thmanyah)

دليل التشغيل الكامل: [SETUP.md](SETUP.md) — قائمة الاختبار: [TESTING.md](TESTING.md)

للمعاينة بدون خادم: افتح الموقع مع `?test=1`.
